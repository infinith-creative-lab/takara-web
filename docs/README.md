# Takara Enterprise Documentation

Welcome to the official developer documentation for the **Takara Enterprise** website. This suite of documents provides a high-level and detailed overview of the application's architecture, security, and performance optimizations.

## Getting Started

1.  **Architecture**: Understand the Next.js 15 App Router and SSG strategy.  
    → [ARCHITECTURE.md](./ARCHITECTURE.md)
2.  **Folder Structure**: Learn the project's organization and component patterns.  
    → [FOLDER_STRUCTURE.md](./FOLDER_STRUCTURE.md)
3.  **Security**: Review the static site security and form protection policies.  
    → [SECURITY.md](./SECURITY.md)
4.  **Performance & Accessibility**: Explore our techniques for CWV and WCAG compliance.  
    → [PERFORMANCE_ACCESSIBILITY.md](./PERFORMANCE_ACCESSIBILITY.md)
5.  **SEO Strategy**: Guide to metadata, JSON-LD, and search optimization.  
    → [SEO_GUIDE.md](./SEO_GUIDE.md)

## Development Workflow

1.  **Installation**: `npm install`
2.  **Dev Server**: `npm run dev`
3.  **Build**: `npm run build`
4.  **Preview**: `npm run start`
